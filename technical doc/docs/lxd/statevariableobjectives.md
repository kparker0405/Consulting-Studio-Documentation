## Strategic-State Variable Objectives & Definitions
### Objectives for the Strategic-State Variables
These are just for informative purposes. For example, in Node 1.1 we have a variable called InitialStrategy, that records the initial project direction. Each choice for that node has a different value for that variable. This is then communicated to the person/group during the recap text. 

It is not based on the score, or any other calculations. It is purely informative and that variable does not change the simulation path. 

### Definitions of the Strategic-State Variables
|State Variable Name| Purpose | Set At|
|Initial Strategy| Records the initial project direction| Node 1.1|
|Midpoint Strategy| Records the strategy after initial adaptation| Node 2.2|
|Final Strategy| Records the strategy near the end| |Node 4.1|
